# Настройки Сёмы — макеты

Комплект из десяти досок холста макетов. Доски — файлы `*.dc.html`,
открываются по одной в браузере; раскладка холста и заметки к доскам —
`canvas.json`.

| Доска | Что на ней |
|---|---|
| `Main.dc.html` | каркас: пять вкладок, список разделов, полоса сохранения |
| `Glavnoe.dc.html` | «Главное»: последняя активность и замечания |
| `Pochta.dc.html` | «Почта»: вкладки ящика, спам, папки и хранение, опасный блок отдельно |
| `Modeli.dc.html` | «Модели»: девять ролей, общий выбор из набора, служебные модели |
| `Bezopasnost.dc.html` | «Безопасность»: доступ, ключи, что ушло наружу |
| `Seychas.dc.html` | замер «как было»: узлы и вес экранов с живого сервера |
| `TelefonVkladki.dc.html` | телефон: полоса вкладок и закреплённый ящик |
| `TelefonShtorka.dc.html` | телефон: нижняя шторка разделов — диалог с фокусом внутри |
| `Poryadok.dc.html` | порядок работ |
| `Karta.dc.html` | карта: куда переехала каждая из настроек |

Отдельный `*.dc.html` — артборд, а не страница: он открывается в браузере как
статичный макет (`support.js` рядом — заглушка редактора холста), но живёт
внутри холста. Числа сняты с живой Сёмы, а имена, адреса и номера в макетах
заменены выдуманными.

Сверено с исправленным интерфейсом 12 сентября 2026: ролей девять; порог спама
подписан «Порог похожести на размеченные вами письма»; шторки — диалоги с
фокусом внутри и Escape; стирание обычных писем с сервера — отдельный опасный
блок со своей кнопкой.
