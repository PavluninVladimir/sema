Кнопка «Почта ▾» открывает разделы вкладки — и ничего больше

Шторка показывает разделы только выбранной вкладки: пять строк для «Каналов», четыре для «Поведения», пять для «Системы». Переключать вкладку отсюда нельзя — для этого полоса наверху, она осталась видна над затемнением. Строка высотой 56 px, точка справа — там есть замечание. Шторка — диалог: role=dialog, aria-modal, фокус при открытии встаёт на первый раздел и ходит по кругу внутри, Escape закрывает и возвращает его на кнопку «Почта ▾», страница под затемнением для чтения вслух не существует. Поле поиска в шторке ищет по разделам этой вкладки; общий поиск по всем настройкам живёт в шапке.
