Это тревога
Один список, одна форма: источник · объект · уровень · строка-итог · поля с уровнем · кнопки решения. В норме серверы сюда не попадают — только строка в блоке на «Почте». Решение уходит туда, где родился запрос (команда — на «Серверы», скилл — на «Скиллы»), здесь остаётся история в «Сделано».
Как сюда пишут · ядро и любой модуль
sema.notify({ key: "server:srv-bots", // тот же ключ — заменяет вчерашнее title: "srv-bots · обновлений 68 (security 41)", level: "warn", // ok | info | warn | alert summary: "перезапуск не нужен · входов 10 · упала служба", fields: [{label: "Обновления", value: "68, security 41", level: "warn"}, …], actions: [{ssh: "srv-bots", cmd: "sudo apt upgrade -y", label: "обновить 68 пакетов"}] }) Уведомления — сущность ядра: таблица, экран, счётчик в меню. Ядро кладёт сюда команды на подтверждение, права, скиллы, отпечатки; модуль «Требует внимания» — письма со сроком и без ответа; «Серверы под присмотром» — отчёты. level «ok» на экран не выводится, только в сводку на «Почте».
