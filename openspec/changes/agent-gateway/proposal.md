## Why

Сёма живёт дома на Raspberry Pi и снаружи недостижима. Из этого растут
сразу три беды: телефон почти весь день без неё, пуши в браузер не
работают вовсе (служба пушей в интернете, а Сёма нет — ключи VAPID лежат
в хранилище без дела), и попасть к ней из дороги нельзя никак.

Открыть порт на домашнем роутере — плохой ответ: домашний адрес светится,
его надо держать постоянным, а на краю не будет ни отсева, ни сертификата
на человеческое имя.

При этом нужное уже наполовину построено. У Сёмы свой удостоверяющий
центр, агенты входят по одноразовому коду, провод идёт по TLS со взаимной
проверкой и работает в обе стороны. Не хватает только того, у кого есть
постоянный адрес и домен.

## What Changes

- Новая роль жителя машины — **шлюз**: держит домен, получает на
  него сертификат сам и пускает к Сёме запросы из интернета.
- **Соединение открывает Сёма**, а не шлюз. Адрес шлюза —
  настройка у Сёмы. Дома не открывается ни один порт.
- Переворачивается только направление TCP: роли TLS остаются прежними,
  Сёма — сервер, шлюз — клиент со своим сертификатом от её центра.
- Провод остаётся тонким управлением; на каждый поток браузера
  открывается своё соединение.
- Отсев на краю: только известные маршруты Сёмы, пределы частоты, потолок
  размера тела, бан после повторных неудач входа.
- Со стороны Сёмы: вход без пароля из своей сети выключается, доверие
  заголовкам прокси включается.

**BREAKING** для способности `agent-link`: правило «соединение открывает
агент» перестаёт быть безусловным.

Следствие, ради которого стоит потерпеть: появится публичный защищённый
адрес — **заработает канал пушей**, который сейчас не работает именно
из-за недостижимости.

## Capabilities

### New Capabilities

- `agent-gateway`: шлюз — публичный вход к Сёме через жителя машины
  с постоянным адресом: домен, сертификат, обратный туннель, отсев
  запросов на краю.

### Modified Capabilities

- `agent-link`: требование «Разговор закрыт и собеседник опознан» больше
  не говорит, что соединение всегда открывает агент. Правило становится
  общим: звонит тот, кого не найти по адресу.

## Impact

- Репозиторий `sema-agent`: новая роль, ACME и хранение сертификата, слушающий
  порт, отсев запросов, перенос потоков в туннель.
- `server/internal/engine/agent_link.go`, `agent_serve.go`: Сёма умеет
  открывать соединение к названному адресу, оставаясь сервером TLS.
- `server/internal/api/agents.go`: адрес шлюза и его состояние на
  экране «Агенты».
- `server/internal/auth`: вход без пароля из своей сети и доверие
  заголовкам прокси становятся частью выката наружу.
- Канал пушей (`engine/push.go`) впервые получает условия для работы.
- Зависимости: ACME берётся из `golang.org/x/crypto` — модуль уже
  подключён, cgo не появляется.
