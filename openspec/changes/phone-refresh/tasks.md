## 2. Гашение родного жеста

- [x] 2.1 Погасить родное потягивание браузера на прокручиваемом блоке страницы (`overscroll-behavior-y`), не задев прокрутку внутри ленты и кода — `overscroll-behavior-y: contain` на `html` и на `.лента`: только ось Y, горизонтальная прокрутка кода, таблиц и полос вкладок не задета
- [x] 2.2 Проверить в Chrome в узком окне, что родная перезагрузка страницы больше не наступает: это надо сделать **до** своего жеста, иначе браузер срабатывает первым и своего не видно — проверено в Chrome в узком окне: метка `window.__метка_жеста` цела, счётчик запросов оболочки за время жестов не растёт

## 3. Сам жест

- [x] 3.1 Жест в `app.js`: начинается только когда прокручивать вверх нечего и внутри того блока, где палец; горизонтальное движение отдаётся боковой панели по нынешнему порогу наклона — жест начинается только при `scrollTop <= 0` внутри `#лента`; вбок отдаётся панели по тому же наклону 1.4
- [x] 3.2 Выключен вовсе при открытой шторке меню и открытой боковой панели
- [x] 3.3 Срабатывание дёргает **существующее** событие обновления экрана (`сёма:обновить` на `#экран`), а не новый запрос: второй дороги обновления не заводить — дёргает существующее `сёма:обновить`; своего запроса к серверу не заведено
- [x] 3.4 Пока обновление идёт, повторный жест не запускает второго — пока идёт, повторный жест не начинается вовсе, знак «Обновляю…» остаётся
- [x] 3.5 Только узкий экран; в широком окне поведение прежнее — только `телефон()` (≤720)

## 4. Что видит человек

- [x] 4.1 Видно начало жеста, пройденный порог и идущее обновление — по макету — четыре вида указателя по макету, высота едет за пальцем, разметка знака пересобирается только при смене состояния
- [x] 4.2 Отпускание раньше порога возвращает экран в прежний вид, обновление не идёт
