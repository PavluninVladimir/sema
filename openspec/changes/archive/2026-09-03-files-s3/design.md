## Context

`storages(name, kind, config, is_primary)`, локальное хранилище по хэшу,
`FileBytes` читает по `storage/key`. Секреты — в хранилище секретов по
имени. Для проверки под рукой MinIO в Docker.

## Decisions

### S3 — зеркало, локальное — основное

Смена основного на S3 не делается: локальная копия остаётся всегда, как у
писем. Зеркало заполняется задачей раз в минуту (до 20 файлов за проход),
у файла хранится `mirror` — имя хранилища, куда он уложен. Чтение: сначала
локально, при ошибке — из зеркала.

### Настройки S3

`config` JSON: `endpoint`, `bucket`, `region`, `prefix`, `ssl`,
`access_secret`, `secret_secret` — имена секретов в хранилище, сами ключи
в справочник не попадают. Клиент — minio-go (чистый Go, без cgo).

### Проверка

`Check`: соединение, `BucketExists` → `MakeBucket`, `Put`/`Get`/`Delete`
объекта `sema-check`. Результат и ошибка — в строке хранилища.

## Risks / Trade-offs

- Зеркало догоняет с задержкой до минуты и по 20 файлов — при первом
  включении на сотни файлов уйдёт несколько минут; прогресс виден в строке.
