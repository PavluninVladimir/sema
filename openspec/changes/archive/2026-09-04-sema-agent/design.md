## Context

На машине уже стоят `rust-analyzer`, `sourcekit-lsp`, `node` и `cargo`;
`gopls`, `typescript-language-server` и `universal-ctags` — нет, ставятся
одной командой. Из ctags стоит старый BSD-вариант от Xcode, он почти
бесполезен.

У Сёмы уже есть половина нужного: клиент MCP по JSON-RPC (написан для
трекеров и проверен на живом сервере), парсер JavaScript в составе goja,
полнотекстовый поиск FTS5 и векторы bge-m3. Правило проекта — **никакого
cgo**, иначе ломается кросс-компиляция под ARM и статическая сборка
образа.

Сёма в контейнере, языковые серверы на машине. Это и определяет форму:
житель машины, а не ещё один воркер внутри Сёмы.

## Goals / Non-Goals

**Goals:**

- Один постоянный житель машины, к которому со временем прирастают
  способности; сегодня их одна — понимание кода.
- Короткая и точная выжимка вместо чтения файлов.
- Один агент на трёх клиентов: Claude Code, Codex, Сёма.
- Любой язык, у которого есть языковой сервер; там, где его нет, —
  плавная деградация с честным ярусом.
- Проверка кода, которого нет на диске.
- Измеримость: сколько строк и токенов сэкономлено.

**Non-Goals:**

- Исполнение чего-либо на машине. Ни правок файлов, ни команд. Это
  отдельное изменение, и оно потребует кругов и подтверждений.
- Свой индекс кода в базе Сёмы. Копия устаревает и создаёт вопрос
  приватности; языковой сервер всегда свежий и читает файлы сам.
- Свои парсеры на tree-sitter: он тянет cgo, а WASM-путь через wazero —
  отдельная большая работа без явной нужды.
- Оценки «риска дефектов» с калиброванными весами: корпуса дефектов у нас
  нет, изображать научность не будем.
- Слой git-аналитики (горячие точки, владельцы): у проекта один автор.

## Decisions

- **Агент, а не безымянный мост.** Понимание кода — первая способность, а
  не вся программа. Дальше на этом же жителе естественно вырастают: клиент
  модели по подписке (сегодняшний мостик к Codex), доступ к папкам,
  локальные проверки. Одна связь с Сёмой, один токен, один журнал.
- **LSP вместо своих парсеров, включая Go и JS.** Своя реализация на
  `go/ast` всегда будет беднее `gopls`: тот знает типы, интерфейсы, кто
  что реализует и иерархию вызовов. Одна дорога для всех языков дешевле
  двух и честнее по точности. Альтернатива (свой AST для Go и JS, LSP для
  остальных) отвергнута: два пути расходятся в поведении и в формате
  карточек.
- **Один демон, много клиентов.** Если каждый агент разработки поднимет
  свой пул, `rust-analyzer` запустится дважды и съест память дважды.
  Плагины у Claude Code и Codex тонкие и говорят с жителем по stdio.
- **Ярус в каждом ответе.** `lsp` — сервер языка ответил; `tags` — символы
  из ctags, граф вызовов приблизительный; `text` — только поиск. Агент
  разработки, не знающий точности ответа, будет уверенно ошибаться.
- **Виртуальные документы.** `textDocument/didOpen` несёт текст, файл на
  диске не нужен. Модули Сёмы не имеют импортов (только глобальные
  `sema.*`), поэтому виртуального документа им достаточно.
- **Ленивый пул с остановкой по бездействию.** Сервер языка поднимается
  при первом вопросе по репозиторию; предел одновременных серверов и время
  бездействия — настройки, а не константы.
- **Только петля и токен.** Житель слушает `127.0.0.1`, для доступа нужен
  токен; Сёма ходит к нему по своей сети. Он видим на экране Сёмы как
  источник, и отданное попадает в журнал «Что ушло».
- **Счёт сэкономленного.** На каждый ответ известно, сколько весил бы файл
  целиком; разница отдаётся Сёме. Без этого нельзя отличить пользу от
  ощущения пользы.

## Risks / Trade-offs

- **Языковой сервер дорог.** `rust-analyzer` на большом проекте — сотни
  мегабайт и минуты первичной индексации. Смягчение: ленивый старт, предел
  одновременных серверов, остановка по бездействию и спайк с замером
  прежде проектирования.
- **Vue 2 — слабое место.** Volar рассчитан на Vue 3, а один из проектов на машине — на Vue 2.
  Вероятно, там останется ярус ctags. Проверяется спайком, обещаний не
  даём.
- **Первый вопрос ждёт индексации.** Смягчение: ответ ярусом `tags` сразу
  и уточнение, когда сервер готов.
- **Ещё один процесс на машине.** Его надо запускать при входе в систему и
  обновлять. Программа на Go без зависимостей, но это всё равно новый
  житель.
- **Соблазн дать агенту исполнять.** Как только он начнёт править файлы и
  запускать команды, к нему придётся применять круги, суд и подтверждения,
  как к серверам. Граница «только чтение» держится намеренно и снимается
  отдельным изменением, а не по ходу дела.
- **Агент видит весь код, включая рабочий.** Он ничего не отправляет
  наружу сам, но становится ещё одним местом, где код проходит. Смягчение:
  петля, токен, журнал отданного и класс чувствительности репозитория.
