## MODIFIED Requirements

### Requirement: Разбор чеков и счетов

Чеки и счета SHALL разбирать встроенный модуль `receipts` на среде модулей
по событиям файла (`file.added`, `file.changed`) из любого источника и по
событию письма для чеков в тексте письма; чек SHALL помнить файл и источник,
а письмо — только если оно было. Для ящиков, закрытых для облачной модели,
извлечение SHALL идти локальной моделью. Ядро SHALL знать о чеках только
через инструменты модуля; при выключенном модуле экраны SHALL работать без
сумм.

#### Scenario: Счёт во вложении

- **WHEN** во вложении лежит счёт на оплату
- **THEN** модуль извлекает получателя, сумму и период, помечает файл как
  чек через ручку ядра, и файл виден в разделе файлов с суммой

#### Scenario: Счёт перетащили в окно

- **WHEN** PDF со счётом загружен без письма
- **THEN** чек появляется в модуле с источником «загрузка» и без ссылки на
  письмо

#### Scenario: Модуль выключен

- **WHEN** модуль «Чеки» выключен
- **THEN** новые чеки не разбираются, дайджест и файлы показываются без
  сумм, а накопленные данные модуля сохраняются
