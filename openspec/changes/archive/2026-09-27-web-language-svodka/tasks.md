## 1. Основание: токены, шрифты, базовые элементы

- [x] 1.1 Шрифты Golos Text и IBM Plex Mono лежат у Сёмы, отдаются оболочкой, в списке публичных путей
- [x] 1.2 Токены светлой и тёмной темы по макету; старые имена указывают на новые значения
- [x] 1.3 Шкала шрифтов из шести ступеней; моноширинный для машинных фактов
- [x] 1.4 Строка списка на бумаге с волосяным разделителем вместо белой карточки с рамкой
- [x] 1.5 «Норма молчит»: заливная капсула только у `alert`, `warn` точкой, `ok`/`info` цветом значения
- [x] 1.6 Заголовок раздела не капслоком, с линией до края
- [x] 1.7 Кнопки, поля, сегменты, тумблер, меню по макету (кнопка-призрак, кольцо фокуса, сегмент 26 точек, тумблер 36×20 синий, троеточие 28×28; на телефоне поле в две строки, тумблер остаётся пилюлей)
- [x] 1.8 Снимки светлой, тёмной и телефона (`снимки-язык-*`); в шапке одно действие, разделы на телефоне в две строки

## 2. Новые компоненты словаря

- [x] 2.1 `metric` — плитка-показатель: значение моноширинным, отдельная единица, уровень полосой; «Здоровье», «Очередь», «Задачи», «Развитие» переехали
- [x] 2.2 `shelf` — полка «ждут вас»; на «Почте» стоит первой, над дайджестом
- [x] 2.3 `alarm` — плашка поломки; «Почта» шлёт её вместо хвоста в подписи экрана
- [x] 2.4 `figs` — строка чисел; шлют «Файлы», «Модули», «Скрипты», «Агенты»
- [x] 2.5 `rowgroup` — подряд идущие строки с одной причиной сворачиваются со счётчиком; включено на отказах «Здоровья»
- [x] 2.6 `table` — таблица с подписями колонок: ячейки у строк (`Cell.Text/Level/Mono`), машинное значение моноширинным по правому краю, управление строки последней колонкой
- [x] 2.7 `matrix` — матрица выдачи прав памяти вместо селекта в строке; словарь 8
- [x] 2.8 Словарь 8: `metric`, `alarm`, `figs`, `shelf`, `rowgroup`, `matrix`; тест словаря зелёный
- [x] 2.9 `chipset` — ряд капсул с хвостом «ещё N» (обрезает сервер: клиент считать влезающее не умеет)
- [x] 2.10 `step` — шаг мастера: сделан, раскрыт, впереди
- [x] 2.11 `crumb` — обратный путь; поднимается из ленты в шапку, над заголовком
- [x] 2.12 Словарь 9: `table`, `chipset`, `step`, `crumb`

## 3. Экраны на новом языке

- [x] 3.1 «Почта»: полка «ждут вас» сверху, поломка плашкой, строка письма в две строки
- [x] 3.2 «Здоровье»: норма молчит, плитки-показатели, повторы отказов свёрнуты
- [x] 3.3 «Память»: матрица выдачи прав
- [x] 3.4 Настройки (обзор, ящик, модели и роли, доступ, серверы, агенты, хранилища, интеграции, инструменты, скиллы) и списки (отправители, файлы, скрипты, модули, уведомления)
- [x] 3.5 Чаты, письмо, «Что ушло», первый запуск и граф на новом языке
- [x] 3.6 Меню: «Ждут вас» закреплено над списком, когда что-то ждёт (словарь 11)
