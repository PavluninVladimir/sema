# Как переносим язык «Сводка» в код

## Порядок

Слой токенов и типографики один меняет вид **всех** экранов, потому что
все правила стиля ходят через переменные. Поэтому первый этап — он, а не
экран за экраном. Дальше добавляются недостающие компоненты UI-DSL, и
только потом экраны переезжают на них.

1. Токены, шрифты, базовые элементы (строка, раздел, капсула, кнопка,
   поле, меню). Ни строки на сервере.
2. Новые компоненты словаря: `metric`, `shelf`, `alarm`, `figs`,
   `rowgroup`, `table`, `matrix`. Каждый — сервер, клиент, словарь, тест.
3. Экраны: «Почта», «Память», «Здоровье», дальше остальные.

## Шрифты

Golos Text (кириллица родная, а не приделанная) и IBM Plex Mono (для
того, что Сёма померил: время, адреса, токены, суммы, номера). Обе под
OFL.

Шрифты лежат **у Сёмы**, а не грузятся из Google: адрес страницы и адрес
человека не должны уходить наружу, а дома интернета может не быть — Сёма
же стоит рядом на Pi. Взяты только латиница и кириллица (322 КБ на восемь
начертаний), отдаются с недельным кэшем и входят в список публичных путей
оболочки: страница входа нужна раньше сессии.

## Токены

Старые имена переменных остаются и указывают на новые значения — тогда
сотни правил, которые уже ходят через `var(--текст)`, меняются сами.
Новые имена добавляются рядом для того, чего раньше не было (полка,
подложка тревоги, вторая линия).

| Было | Стало | Что это |
|---|---|---|
| `--фон` #f5f5f7 | #FBFAF7 | бумага, а не серый холст |
| `--карточка` #fff | #FFFFFF | панель — только там, где нужен блок |
| `--меню-фон` #efedea | #F4F2EC | рельс меню |
| `--текст` #1d1d1f | #17181C | чернила |
| `--тихий` rgba(60,60,67,.6) | #585B64 | второй уровень, не прозрачность |
| `--едва` | #8B8E97 | третий уровень |
| `--линия` | #E3E0D8 | граница блока |
| `--линия-тонкая` | #EFECE4 | волос между строками |
| `--свой` #0071e3 | #1F4FD8 | акцент |
| `--ok/info/warn/alert` | #2E7D4F / #2A5FCC / #9C6100 / #BE3320 | состояния |

Тёмная тема — полноценная пара, а не инверсия: `--paper` #131417,
`--panel` #1B1D21, `--ink` #ECEDEF, акцент светлеет до #87A9FF.

## Шкала шрифтов

Было четыре размера (20 / 13 / 11 / 10), на деле три: 11 и 10 не
различаются. Стало шесть, и каждая ступень отвечает за одно:

| Размер | Где |
|---|---|
| 28/700 | заголовок экрана |
| 32/600 моно | показатель, деньги |
| 15/600 | строка списка — то, что ищут глазами |
| 15/400 | текст и пояснения |
| 12/600 | подпись, заголовок раздела, метка поля |
| 11/500 моно | машинный факт: время, адрес, id, токены |

Заголовки разделов — не капслоком.

## Норма молчит

Четыре уровня остаются, но выражаются по-разному:

- `alert` — заливная капсула: только то, что ждёт человека;
- `warn` — точка со словом;
- `ok` и `info` — цвет самого числа или ничего: «в норме» вообще не
  рисуется, отсутствие тревоги и есть норма.

## Что нельзя сломать

- Словарь UI-DSL — договор: новый тип компонента без строки в
  `web/dictionary.txt` роняет тест, а не экран у человека. Каждый новый
  тип поднимает `UIDictVersion`.
- Защита от чужого сайта, `HX-Request` у `/do` и `/upload`, проверка
  источника — при правках разметки не трогаются и проверяются тестами.
- Телефон равноправен: каждый этап проверяется снимком на 390 точках, и
  ни один элемент не должен быть шире экрана.
