## Why

Житель машины умеет отдавать карточку кода вместо файла (168 строк
вместо 1483 на замере), но за месяц его спросили пять раз: инструменты
у Claude Code отложены и не видны модели, а знание о месте живёт за
второй дверью (`code_knowledge` — два вызова за всю историю). В итоге
агенты разработки читают файлы целиком, а накопленные принципы, требования
спек и грабли до них не доходят — код пишется дороже и хуже, чем мог бы.

## What Changes

В порядке внедрения — каждый шаг проверяется счётчиком сэкономленного,
и следующий делается только если предыдущий сработал.

- **В. Чтобы спрашивали.** Ответ хука начала сессии (`additionalContext`)
  несёт короткую подсказку: для понимания кода — карточки жителя машины
  (`symbols`, `context`, `impact`), а не чтение файла целиком; у Claude
  Code инструменты отложены, их надо загрузить. Подсказка — часть ответа
  жителя, CLAUDE.md не трогается.
- **А. Дверь одна.** Карточка `symbols`/`context` сама несёт приложение
  «что здесь известно»: житель машины спрашивает Сёму по проводу одним
  запросом и дописывает ответ в пределах предела. Отдельный
  `code_knowledge` остаётся для явного вопроса, но не обязателен.
- **Б. Место — это и пакет.** Привязка знания расширяется с «файл +
  символ» до «папка/пакет»: принципы уровня `internal/api/*` приходят в
  карточку любого файла этого пакета. Источник принципов — абзацы
  «Архитектуры» и «Правил проекта» CLAUDE.md, которые называют пути:
  житель машины (он видит файлы) разбирает их и заводит привязки
  «пакет ← абзац, источник, хэш»; в памяти лежит ссылка и одна строка,
  не копия; изменился абзац — привязка пересобирается по хэшу.

Не меняется: сам CLAUDE.md, формат уроков и кристаллов, права на области
памяти (приложение приходит только по выданным областям).

## Capabilities

### New Capabilities

- (нет)

### Modified Capabilities

- `code-memory`: место в коде — не только файл и символ, но и
  папка/пакет; приложение к карточке отдаётся самим жителем машины
  вместе с карточкой, а не отдельным вызовом; принципы из CLAUDE.md
  живут в памяти ссылкой с хэшем и пересобираются при изменении абзаца.
- `sema-agent`: ответ хука начала сессии подсказывает, как понимать код
  дешевле; карточки кода несут приложение из памяти в пределах предела и
  честно говорят, когда память недоступна.

## Impact

- репозиторий `sema-agent`: `cmd/semaagent/hook.go` (ответ хука),
  `internal/lsp/cards.go` + провод к Сёме (приложение к карточке),
  разбор CLAUDE.md по путям и хэшу (новый файл), счётчик `savings` —
  отдельная строка «карточек с приложением».
- `server/`: `store/memory.go` — `memory_places` с уровнем «папка»,
  `engine/memory.go` — `PlaceKnowledge` понимает пакет, метод провода
  `память.code_knowledge` принимает список мест; экран «Память» — привязки
  уровня папки видны и снимаются человеком.
- Токены: +1 запрос по проводу на карточку, ответ ограничен
  `code.knowledge_chars`; при недоступной Сёме карточка приходит без
  приложения с пометкой, а не ждёт.
