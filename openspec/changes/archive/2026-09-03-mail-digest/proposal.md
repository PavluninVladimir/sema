## Why

Экран «Почта» сегодня — разбор спама. Когда разбирать нечего (а это почти
всегда), там строка «всё разобрано» и хвост спама. При этом у Сёмы есть всё,
чтобы быть полезнее почтового клиента: он уже вытащил из писем чеки, суммы,
документы, отправителей и знает, кто человек, а кто робот. И главное — из
писем выпадают сроки и просьбы: «оплатить до 10-го», «ответьте по срокам»,
приглашение на встречу. Сегодня они теряются вместе с письмом.

## What Changes

- **Дайджест на «Почте»**: сверху сводка за окно (сегодня / с прошлого захода
  / неделя — настройка): письма не-спам по группам (счета и чеки с суммами,
  документы с именами файлов, от людей, уведомления свёрнуто); группы —
  справочник в базе с первичным набором. Разбор спама показывается, только
  когда есть что разбирать. Работа Сёмы — одной строкой с раскрытием.
- **«Требует внимания» — встроенный модуль** на среде из `module-platform`,
  а не код ядра: подписан на события «письмо» и «файл», хранит напоминания
  в своей коллекции (текст, срок, письмо-источник, ящик, состояние: ждёт /
  сделано / отложено / просрочено), правила извлечения — в его коллекции с
  правкой на его экране: вид письма → когда напомнить → сразу или
  предложить. Извлекает модель роли модуля; для ящиков, закрытых от
  облака, — локальная. Два вида: срок из письма и «без ответа через N
  дней». Приглашения `.ics` тоже становятся напоминаниями.
- Блок раздела на «Почте»: ближайшие сверху, просроченные красным, у каждого
  источник и кнопки «сделано», «отложить», «открыть письмо». Наступивший
  срок — вверх списка и сообщение в чат; уведомление macOS — позже.
- **Чат**: «напомни про это письмо в пятницу» → инструмент модуля
  `attention.remind` в скрипте из чата, карточка, запись; наступивший срок
  модуль пишет в чат. Другие модули пользуются тем же инструментом.
- Задача модуля «Сроки» в общем списке задач: выключается, расписание
  правится. Раздел «Требует внимания» на «Почте» рисует ядро из вклада
  модуля. Макеты — до кода.

## Capabilities

### New Capabilities

- `mail-digest`: сводка «Почты» по группам с окном и справочником групп.
- `attention`: напоминания из писем, правила извлечения, состояния, экран,
  доставка при наступлении срока.

### Modified Capabilities

- `assistant-chat`: напоминание из чата через инструмент модуля с карточкой.
- `dynamic-ui`: раздел «Почта» открывается дайджестом, разбор — при
  необходимости.

Зависит от `module-platform`: события, коллекции, контекст, формы.

## Impact

- `store`: таблица `digest_groups`; настройки окна дайджеста. Напоминания и
  правила — коллекции модуля, таблиц ядра нет.
- `server/modules/attention.js`: встроенный модуль — обработчики событий,
  коллекции `items` и `rules`, задача «Сроки», экран с формами правил,
  инструмент `attention.remind`, функция контекста.
- `engine/digest.go`: группировка писем за окно; `api/inbox.go`: дайджест,
  раздел «Требует внимания» из данных модуля, условный разбор.
- Клиент не пересобирается.
