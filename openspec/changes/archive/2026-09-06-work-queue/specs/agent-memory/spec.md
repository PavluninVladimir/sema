## ADDED Requirements

### Requirement: Работа памяти идёт через очередь

Разбор записей, кристаллы сессий, извлечение графа и векторы SHALL ставиться
в очередь ядра, а не выбираться сканированием на каждом проходе. Экран
«Память» SHALL показывать, сколько работы ждёт, и вести на экран «Очередь».

#### Scenario: Запомнили факт

- **WHEN** Сёма запомнил новый факт
- **THEN** в очереди появляются работы «вектор», «граф» и «разбор» для этой
  записи, и они выполняются по очереди, а не при следующем полном проходе
