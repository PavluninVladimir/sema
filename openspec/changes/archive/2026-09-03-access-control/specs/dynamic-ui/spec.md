## ADDED Requirements

### Requirement: Экран входа

Клиент SHALL показывать экран входа с кнопкой «Войти с passkey», когда
сервер отвечает 401, и SHALL предлагать завести первый ключ, когда сервер
сообщает, что ключей нет и запрос идёт с самой машины.

#### Scenario: Первый запуск на Pi

- **WHEN** человек открывает клиент, подключённый к Pi без ключей, с самого Pi
- **THEN** мастер предлагает завести passkey и после этого открывает Сёму
