## ADDED Requirements

### Requirement: `sema.notify` и `sema.remind` в песочнице

Каждый модуль SHALL иметь `sema.notify` и `sema.remind` без отдельного
права; источник записи — имя модуля, команды в действиях — только на
выданных модулю серверах. Новые права обновлённого из чата модуля SHALL
появляться уведомлением с кнопкой «Выдать».

#### Scenario: Команда на чужой сервер

- **WHEN** модуль кладёт действие с сервером, который ему не выдан
- **THEN** уведомление сохраняется без этой кнопки, а в журнале модуля —
  отказ
