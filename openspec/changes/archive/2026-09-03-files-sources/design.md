## Context

`Engine.AddFile(name, mime, data, source, msg)` принимает файл из любого
источника, считает хэш, кладёт в хранилище, извлекает текст и эмитит
`file.added`. Загрузка через `POST /api/files` уже есть. Экран «Хранилища»
показывает источники, папка и модули там помечены «скоро».

## Goals / Non-Goals

**Goals:**

- Скан из папки и файл от модуля попадают в Сёму так же, как вложение.
- Файл можно показать Сёме в чате и спросить о нём.
- Ничего не зашито: папки — справочник, поведение после приёма — настройка.

**Non-Goals:**

- Слежение за папкой через inotify: раз в минуту достаточно.
- Синхронизация обратно (Сёма ничего в папку не пишет).
- Просмотр файла внутри чата — открываем системным приложением.

## Decisions

### Папки — справочник с задачей раз в минуту

`file_folders(id, path, enabled, delete_after, created)`; задача
`files_folders` обходит включённые папки (без рекурсии — первый уровень,
рекурсия отдельной галочкой позже), пропускает файлы, изменённые меньше
10 секунд назад (ещё пишутся), и те, что уже приняты: `folder_seen(path,
size, mtime, file_id)`. Новый или изменившийся файл идёт в `AddFile` с
источником `folder:<путь>`; при `delete_after` — удаляется после успешного
приёма. Ошибка чтения одного файла не останавливает обход.

В Docker папка хозяина видна только через том: в `docker run` и compose
добавляется `-v ~/Inbox:/data/inbox:ro` (или без `:ro`, если удалять после
приёма); справочник по умолчанию содержит `/data/inbox` выключенной, с
подсказкой, как примонтировать.

### `sema.files.add` — тот же AddFile

Право `files` уже даёт `sema.files` и `sema.files.mark`; добавляются
`files.add(name, content, {mime, base64})` → id и `files.text(id)` → текст.
Источник `module:<имя>`. Модуль получит `file.added` на свой файл, если
подписан — это не цикл: событие на уже известный хэш не эмитится.

### Файл в чат

Клиент при drop на экране `chat:<id>` загружает файл с `origin=chat:<id>`
и после успеха шлёт действие `attach_file` с id файла: сервер добавляет
сообщение пользователя «📎 имя (#id)» с чипом файла (`filesList` у строки
сообщения). `namedFiles` в сборке контекста кроме имён ищет `#<id>` и файлы,
присланные в этот чат (источник `upload` с ref `chat:<id>`), поэтому
«что в этом документе?» работает и без имени.

## Risks / Trade-offs

- **Права на примонтированную папку**: контейнер работает от uid 10001;
  папка должна быть читаема. Экран показывает ошибку чтения папки прямо в
  строке справочника.
- **Большие папки**: обход первого уровня раз в минуту дёшев, но папку с
  тысячами файлов лучше не подключать; предел файлов за проход — 50.
