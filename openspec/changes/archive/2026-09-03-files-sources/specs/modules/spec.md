## ADDED Requirements

### Requirement: Модуль кладёт и читает файлы

По праву `files` в песочнице SHALL быть `sema.files.add(name, content,
{mime, base64})`, возвращающий id файла, и `sema.files.text(id)`,
возвращающий извлечённый текст; файл модуля SHALL проходить тот же путь,
что вложение: хэш, хранилище, извлечение текста, событие.

#### Scenario: Модуль сохранил файл

- **WHEN** модуль вызвал `sema.files.add("отчёт.txt", текст)`
- **THEN** файл виден в «Файлах» с источником «модуль», текст доступен через
  `sema.files.text(id)`
