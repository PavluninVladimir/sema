## 2. Сёма

- [ ] 2.1 Сервер gRPC на том же 8443: разбор по `Content-Type: application/grpc`, остальное — прежний маршрутизатор
- [ ] 2.2 Перехватчик входа: сессия и токен из метаданных, локальный адрес из `peer`, `ScopeFor` для методов, `mayAdmin` для действий доступа
- [ ] 2.3 `Screen`: документ сразу, затем по подписке на узел сигналов; отправка только если документ изменился; отмена по контексту
- [ ] 2.4 `Act`: тот же `execute` и `buildScreen`; экран «Обновите клиент» при старой версии
- [ ] 2.5 Тесты: поток отдаёт новый документ по сигналу и молчит без изменений; вход и права; действие без права «действия»
