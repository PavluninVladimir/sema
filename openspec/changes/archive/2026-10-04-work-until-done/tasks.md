## 2. План и разбор блоков

- [x] 2.1 Разбор ```` ```sema-plan ```` (строка «цель:», пронумерованные шаги, необязательные «проект:» и «задача:») в `finishWithScripts`: новое поручение или замена несделанных шагов действующего; предел шагов; карточка поручения в чате.
- [x] 2.2 Разбор ```` ```sema-step:done|wait|fail ````: итог шага, переход к следующему, закрытие после последнего, ожидание человека с вопросом, неудача — попытка.
- [x] 2.3 `sema-done` в чате с поручением закрывает поручение; срок жизни ставится только чату, у которого он уже был.
- [x] 2.4 Подсказка модели в промпте чата: большая просьба — план, а не обещание; контекст действующего поручения в каждом ответе этого чата.

## 3. Ход по шагам

- [x] 3.1 Задача ядра «Поручения» (каждые 2 мин): берёт активные поручения без ждущих кнопок, таймера и идущего ответа; ход модели по текущему шагу с указанием «сделай шаг сейчас»; ход без итога шага — попытка; предел попыток — ожидание человека; срок поручения — ожидание человека.
- [x] 3.2 Возобновление: сообщение человека в чате ждущего поручения переводит его в работу.
- [x] 3.3 Telegram: в ветке админ-чата строка шага, вопрос и итог поручения уходят в Telegram (только от хода ядра).
- [x] 3.4 Секреты: модуль, поставленный по поручению, просит секрет, которого нет — шаг ждёт, карточка «Заведите секрет» с переходом `settings:secrets@new~name:<имя>`; секрет появился — поручение продолжается.

## 4. Трекер

- [x] 4.1 При старте — создание задачи в трекере (сервер `assign.tracker`, «auto» — открытый чату сервер с инструментом создания); вызов без привязки к чату; номер задачи из ответа, а при кнопке — после её нажатия.
