## 5. Пуши как канал уведомлений

- [x] 5.1 канал `web` в `notify_channels` на общих правилах: порог, источники, тихие часы, отметка доставки — та же `deliver`, что у остальных

- [x] 5.8 состав пуша по правилу: обычное — заголовок и итог; письмо из закрытого ящика или «секретное» — только «Сёма: есть новое»; письмо не найти — тоже молчим. Тест `TestContentPush`
