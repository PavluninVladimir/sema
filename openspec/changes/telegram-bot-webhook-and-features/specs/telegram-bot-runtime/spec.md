## Purpose

Владелец подключённого бота Telegram управляет приёмом событий, ответами и модерацией из карточки бота и через API Сёмы.

## ADDED Requirements

### Requirement: Управление webhook Telegram

Сёма SHALL показать URL для настроенного публичного HTTPS-адреса и регистрировать или снимать webhook при переключении. Входящие события MUST проверяться секретом заголовка. Состояние дедупликации SHALL переживать рестарт.

#### Scenario: Включение webhook

- **WHEN** владелец включает webhook на карточке Telegram-бота
- **THEN** Telegram получает HTTPS URL и секрет
- **AND** повторная доставка одного обновления не повторяет действие

#### Scenario: Другой обработчик

- **WHEN** Telegram сообщает, что бот уже использует другой webhook
- **THEN** Сёма сообщает о конфликте и сохраняет чужой webhook

### Requirement: Настраиваемые функции бота

Сёма SHALL позволять включать команды, приветствия, личный автоответ, фильтры ссылок, слов и флуда отдельно. Групповые функции MUST выполняться только для разрешённых групп. Проверка спама MUST исключать администраторов.

#### Scenario: Спам-ссылка в разрешённой группе

- **WHEN** обычный участник публикует ссылку при включённом фильтре
- **THEN** бот удаляет сообщение при наличии необходимых прав в Telegram

### Requirement: API управления ботом

Сёма SHALL показать в карточке отдельный URL для получения и изменения настроек бота и путь отправки текстового сообщения. Владелец SHALL иметь возможность выдавать и отзывать токены Сёмы для этого API через «Вход и доступ». В выдаче MUST отсутствовать секреты.

#### Scenario: Запрос с токеном без права управления ботами

- **WHEN** клиент с токеном без права управления ботами Telegram или полного доступа обращается к API управления
- **THEN** Сёма возвращает отказ

#### Scenario: Внешний сервис управляет ботом

- **WHEN** сервис вызывает URL бота с токеном Сёмы с правом управления ботами Telegram
- **THEN** он может читать и менять настройки бота и отправлять сообщения через этот API
- **AND** это право не даёт доступа к другим ресурсам Сёмы
