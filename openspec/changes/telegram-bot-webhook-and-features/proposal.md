## Why

Проверенный токен Telegram пока позволяет только узнать личность бота. Владелец хочет включать приём обновлений и выбирать поведение бота из его карточки или через API Сёмы.

## What Changes

- Показывать URL webhook, переключатель регистрации и проверку состояния.
- Показывать отдельный URL API бота и управлять webhook, функциями и отправкой сообщений через авторизованный API Сёмы.
- Выдавать сервисам отдельные токены с правом управления ботами Telegram.
- Добавить приветствия, команды, личный автоответ и фильтры спама для выбранных групп.

## Capabilities

### New Capabilities

- `telegram-bot-runtime` — webhook и включаемые функции подключённых ботов Telegram.

## Impact

Карточка бота, HTTP-маршруты, Bot API Telegram и хранилище конфигурации. Личные аккаунты и управление ботами MAX продолжают работать по действующим правилам.
