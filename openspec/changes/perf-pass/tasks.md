## 4. Индекс настроек

- [x] 4.1 По замеру из 1.4 найти, что подорожало с 90 мс до 1,2–1,7 с, и снять причину.
  Две причины. На Pi — разбор `modules.json`/`models.json` на каждом экране индекса (снято в разделе 2). На маке и в браузерном обходе — «Обзор» звал `Tools()`, а тот при первом вызове собирал помощник OCR компилятором `swiftc` (442 мс на тесте, 1,7 с в обходе): теперь `HaveOurOCRNow` не ждёт, проверка — в фоне при `Run`, помощник — в кэше пользователя с отпечатком исходника.
