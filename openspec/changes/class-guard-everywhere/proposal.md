## Why

Правило «секретное не уходит облачной модели никогда» записано в спеке
`model-audit` и выполняется ровно в одном месте — при сборке контекста чата
(`outsideCut`). Все остальные дороги к модели проверки не знают:

- **разметка писем** зовёт `e.provider(e.ActiveProvider())`, а не модель роли
  «Фильтр писем», и не смотрит на закрытость ящика: отправитель, тема и
  выжимка каждого входящего уходят наружу, включая ящик, помеченный закрытым;
- **чтение картинок** проверяет только бюджет: скан паспорта уезжает облачной
  модели, а класс файла считается позже — по тексту, который эта же модель и
  вернула;
- **эмбеддинги** зовут `e.embedder.Embed` напрямую: если эмбеддер сетевой,
  векторизуется всё подряд без единой проверки;
- **журнал «Что ушло»** ставит класс по тексту промпта, поэтому отправка
  картинки записывается как «обычное» — журнал не врёт намеренно, но и правды
  не показывает.

Пока модели стояли дома, изъян был невидим. После переезда на Raspberry Pi
домашних моделей почти не осталось, и каждая из этих дорог ведёт наружу.

## What Changes

- Проверка класса становится общей: одна точка (`mayGoOutside`), через которую
  проходит **любой** путь к модели, а не только контекст чата.
- Разметка писем берёт модель роли «Фильтр писем», а не `llm.active`.
- Письмо из закрытого ящика и письмо класса «секретное» размечаются только
  домашней моделью. Домашней нет — письмо остаётся неразмеченным с честной
  пометкой, а не уходит наружу.
- Картинка сначала читается своим OCR, класс считается по имени файла и тексту
  OCR, и лишь потом решается, показывать ли её модели. **Класс может только
  подниматься**; понизить его вправе только человек.
- Приметы класса пополняются признаками документов: строка MRZ паспорта,
  СНИЛС, ИНН, водительское удостоверение, свидетельство, полис.
- Картинка без распознанного текста — отдельный случай с настройкой
  «отдавать / спрашивать / не отдавать», по умолчанию «спрашивать»: улик нет,
  а молчание не разрешение.
- Эмбеддер получает признак «свой или наружу» (по адресу). Наружу секретное не
  векторизуется, и отказ виден в журнале.
- В журнал «Что ушло» класс приходит от самой сущности (письма, файла), а не
  угадывается по тексту промпта.

## Capabilities

### Modified Capabilities

- `model-audit`: правило про секретное перестаёт быть правилом одного места —
  требование распространяется на все пути к модели (разметка, зрение,
  эмбеддинги, модули, поиск), и журнал получает класс сущности, а не промпта.
- `mail-triage`: разметка входящих SHALL идти моделью роли «Фильтр писем», а
  для закрытого ящика — только домашней моделью.
- `files-extraction`: чтение картинки SHALL начинаться со своего OCR, класс
  считается до показа модели, картинка без текста подчиняется настройке.

## Impact

- `server/internal/engine`: `classes.go` (общая проверка, приметы документов),
  `engine.go` (разметка), `vision.go` (порядок OCR → класс → модель),
  `rag.go` (эмбеддинги), `audit.go` (класс сущности в журнале),
  `ocr.go` (настройка для картинок без текста).
- Экраны: карточка файла показывает класс и «модели не показывал»,
  «Что ушло» — правдивый класс, настройка картинок без текста.
- Совместимость: поведение меняется только в сторону запрета. Ящики, не
  помеченные закрытыми, и обычные письма работают как раньше.
