## 1. Уровень самостоятельности (этап 1)

- [x] 1.1 `hosts.autonomy` вместо `hosts.auto`: миграция (`auto=1` → «суд»),
  `Host.Autonomy`, выборки; уровень «полная» запрещён машине-хозяину и
  серверам без sudo
- [x] 1.2 `courtAllowed` смотрит уровень; круг «только человек» проходим
  только на «полной» и только со страховкой
- [x] 1.3 Экран «Серверы»: уровень списком вместо тумблера, окно, потолок,
  «шагов за смену», стоп-кран возвращает всех на «ручное»
- [x] 1.4 Тесты: переезд тумблера в уровень; на «под судом» круг `human`
  уходит человеку; «полная» недоступна хозяину и серверу без sudo

## 2. Возврат и страховка (этап 2)

- [x] 2.1 Разбор арбитра получает поле «возврат»; шаг без возврата или без
  пробы уходит человеку
- [x] 2.2 `safety.go`: страховка возврата — завести отложенный возврат на
  сервере (Linux: сторож с `sleep` и снимком файла; RouterOS: планировщик),
  снять её после успешной проверки, распознать сработавшую
- [x] 2.3 Проверка после изменения идёт **новым** соединением; не открылось
  — тревога, пауза сервера, страховка отрабатывает сама
- [~] 2.4 Настройки: срок страховки (`auto.rollback_min`) есть и виден в
  фактах сервера; пределы ночной смены заведены настройками
  (`night.max_steps`, `night.look_max`, `night.look_timeout_s`,
  `night.every_h`, `night.skill.<род>`) — на экран «Серверы» их выносит
  правка интерфейса
- [x] 2.5 Тесты: страховка ставится до команды и снимается только после
  сошедшейся пробы; потеря связи не снимает страховку; на «под судом»
  страховка не заводится, потому что круг `human` туда не пускают

## 3. Ночная смена (этап 3)

- [x] 3.1 Осмотр: читающие команды по роду сервера из скилла
  администрирования, без суда, с пределом времени (`night_shift.go`:
  `nightLookCommands` — ограждение ```sema-осмотр``` в скилле, иначе всё,
  что скилл показывает кодом; круг чтения здесь и фильтр, и охрана)
- [x] 3.2 Наряд: роль «Арбитр» по осмотру составляет шаги (что, зачем,
  команда, проба, возврат); пустой наряд — нормальный итог
- [x] 3.3 Выполнение по одному через суд и `runByCourt`; перед каждым шагом
  заново проверяются окно, потолок, пауза и стоп-кран
- [~] 3.4 Задача сердцебиения «Ночная смена» (раз в 5 минут, по умолчанию
  выключена) есть, шаги помечены в `ssh_log` (`who` = «ночная смена · <сервер>»);
  отдельной таблицы журнала смены нет — смена видна отчётом в «Уведомлениях»,
  строкой результата задачи и записями `ssh_log`
- [x] 3.5 Отчёт: одна запись в «Уведомления» по окончании смены (`night:<сервер>`),
  беда — тревога сразу и остановка сервера; поток записей о каждой команде
  ночью погашен (`SSHOrigin.Quiet`)
- [x] 3.6 Тесты на поддельной модели (`night_shift_test.go`): наряд из двух
  шагов по одному, шаг без возврата ждёт человека, окно кончилось — остаток
  отложен, несошедшаяся проба останавливает сервер и поднимает тревогу,
  осмотр берётся из скилла и только читающий, смена одна на окно
