## 1. Метки входа в Сёме (спеки gateway-only-access, access-control)

- [ ] 1.1 `gatewayListener` — `net.Listener` поверх канала соединений; отдельный `http.Server` с тем же обработчиком и `ConnContext`, который ставит метку входа.
- [ ] 1.2 `openGatewayStream` кладёт соединение из туннеля в `gatewayListener`, а не набирает свой же порт по петле.
- [ ] 1.3 Правила доступа (`auth.Identify`, `IsLocal`, `canRegister`, фраза) читают метку: шлюз — никогда не локальный, фраза только на заведение ключа; аварийный вход — фраза даёт полную сессию; петля контейнера — локальная.
- [ ] 1.4 `X-Forwarded-For` принимается только на входе шлюзов; общий `auth.trust_proxy` убрать с экрана, прежний ключ не мешает.
- [ ] 1.5 Тесты: поток из туннеля при включённом `local_open` — экран входа; подложный `X-Forwarded-For: 127.0.0.1` не делает его локальным; заголовок на аварийном входе не принимается. Оба `security_regress_test.go` зелёные.
