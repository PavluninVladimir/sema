## Purpose

К Сёме ходят только через агентов: снаружи — через шлюз на машине с
постоянным адресом, дома на маке — через шлюз жителя машины. У самой Сёмы
нет HTTP в сети. Аварийный вход есть, но требует ключа SSH к машине
Сёмы.

## ADDED Requirements

### Requirement: У Сёмы нет HTTP в сети

В режиме «только через шлюз» Сёма SHALL NOT принимать HTTP и HTTPS ни на
одном сетевом адресе машины. Её HTTP SHALL слушать только петлю внутри
контейнера (проверка здоровья, разбор на месте) и петлю самой машины для
аварийного входа. Свой TLS-порт для браузера SHALL NOT открываться:
TLS для браузера держат шлюзы. Провод агентов (TLS со взаимной проверкой)
SHALL оставаться единственным, что машина Сёмы слушает в сети.

#### Scenario: Попытка по старому адресу

- **WHEN** устройство в домашней сети открывает `http://<адрес Pi>:8765`
  или `https://<адрес Pi>:8443`
- **THEN** соединение не устанавливается

#### Scenario: Самоосмотр

- **WHEN** владелец запускает самоосмотр Сёмы
- **THEN** он видит список всего, что Сёма слушает, и предупреждение, если
  что-то, кроме провода агентов, слушает не петлю

### Requirement: Поток от шлюза никогда не «с этой машины»

Каждое соединение SHALL нести метку входа, через который пришло:
- шлюз на машине с адресом;
- шлюз жителя машины;
- аварийный вход;
- петля контейнера.

Решения о доступе SHALL опираться на метку, а не на адрес соединения.
Запрос, пришедший через шлюз, SHALL NOT считаться запросом «с этой машины»
ни при каких настройках. Заголовок с настоящим адресом обратившегося SHALL
приниматься только на входе шлюзов и SHALL NOT приниматься на остальных.

#### Scenario: Поток из туннеля

- **WHEN** запрос из интернета пришёл через шлюз, а настройка «с этой
  машины без входа» включена
- **THEN** запрос без сессии получает экран входа, а не Сёму

#### Scenario: Подложный адрес

- **WHEN** запрос через шлюз несёт заголовок с адресом `127.0.0.1`
- **THEN** он не становится локальным, и в журнале доступа стоит адрес,
  который поставил шлюз

#### Scenario: Заголовок мимо шлюза

- **WHEN** запрос на аварийный вход несёт заголовок с настоящим адресом
  обратившегося
- **THEN** заголовок не принимается

### Requirement: Аварийный вход через SSH

На петле машины Сёмы SHALL быть аварийный вход: попасть на него можно
только с ключом SSH к этой машине. На аварийном входе контрольная фраза
SHALL открывать полную сессию. Последний аварийный вход SHALL быть виден на
«Здоровье».

#### Scenario: Шлюзы недоступны

- **WHEN** VPS-шлюз не работает, а мак не дома
- **THEN** владелец открывает SSH-туннель к машине Сёмы, входит фразой на
  `http://localhost:8765` и видит Сёму целиком

### Requirement: Агент входит по приглашению через шлюз

Вход нового агента по одноразовому коду SHALL быть доступен через шлюз и
через аварийный вход, а не по открытому HTTP. По умолчанию агент SHALL
идти на публичный адрес Сёмы.

#### Scenario: Новый житель машины

- **WHEN** человек создал приглашение и запустил вход агента с кодом
- **THEN** агент получает сертификат через шлюз и дальше звонит по
  проводу агентов
