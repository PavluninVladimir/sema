## Why

Сегодня в Сёму входят тремя дорогами разом:
- открытым HTTP на `:8765`;
- своим TLS на `:8443`;
- проводом жителя машины на `:8766`.

Первые две опубликованы из контейнера на все адреса Pi. Вход без ключа
решает настройка «своя сеть», а адрес в браузере у человека с портом и
`.local`. Снаружи Сёмы не видно, пока не запущен шлюз из `agent-gateway`.

Владелец решил: **к Сёме ходят только через агента, по чистому 443,
HTTP в сети нет**. Снаружи — шлюз на VPS. Дома на маке — свой шлюз у
жителя машины. Телефон всегда идёт через VPS.

## What Changes

- **HTTP Сёмы уходит из сети.**
  - Порты `8765` и `8443` из контейнера не публикуются.
  - Свой TLS-порт `8443` снимается.
  - HTTP остаётся только на петле внутри контейнера, куда шлюзы вносят
    потоки, а для аварийного входа — на петле самого Pi
    (`127.0.0.1:8765` хоста). Туда попадают только SSH-туннелем.
- **Потоки от шлюзов — отдельный вход, который никогда не считается
  локальным.** Сейчас поток из туннеля приходит от 127.0.0.1, а это для
  Сёмы «сама машина». В режиме «только через шлюз» вход без ключа «с этой
  машины» для таких потоков невозможен построением, а не настройкой.
- **Шлюз на маке** — новая способность жителя машины:
  - слушает `127.0.0.1:443`;
  - сертификат на домен Сёмы выдаёт его отдельный корень, который один
    раз кладётся в Связку ключей;
  - потоки идут к Сёме по проводу, который мак уже держит (звонит мак);
  - нет провода (мак вне дома) — шлюз передаёт поток на VPS-шлюз.
- **Один адрес везде** — `https://sema.example.org`. На маке имя ведёт
  на `127.0.0.1`, снаружи — на VPS.
- **Ключи входа заново.** Ключи входа (passkey) переезжают с `sema.local`
  на домен: вход контрольной фразой, ключи заводятся заново (сценарий
  «Переезд на домен» из `login-phrase`).
- **Край — забота шлюза, а не Сёмы.** Браузеру шлюз отдаёт только 443 с
  HSTS; порт 80 у шлюза остаётся под проверку сертификата Let's Encrypt.
  DNS-API регистратора домена не нужен.
- **Живой запуск шлюза** (`agent-gateway`, задачи 7.1–7.6) — часть этой
  работы.

**BREAKING**:
- адреса `http://sema.local:8765` и `https://sema.local:8443` перестают
  работать;
- прежние ключи входа не пускают на новом адресе;
- без интернета телефон до Сёмы не достучится, а мак — только если он
  дома.

## Capabilities

### New Capabilities
- `gateway-only-access`:
  - Сёма не слушает сеть по HTTP;
  - вход только через шлюзы;
  - поток от шлюза никогда не локальный;
  - аварийный вход SSH-туннелем к петле Pi;
  - что видно человеку, когда шлюз недоступен.
- `local-gateway`: шлюз жителя машины на маке:
  - `127.0.0.1:443`;
  - свой корень в Связке ключей;
  - потоки по проводу агента;
  - переход на VPS-шлюз вне дома.

### Modified Capabilities
- `agent-link`: по проводу жителя машины ходят не только вызовы, но и
  потоки браузера, которые открывает мак.
- `access-control`: в режиме «только через шлюз» вход без ключа «с этой
  машины» невозможен; адрес ключей входа — домен.

`agent-gateway` (VPS-шлюз) архивируется до этого изменения: правки края —
HSTS и закрытый порт 80 — ложатся в его спеку после архива.

## Impact

- **Сервер:**
  - `api/server.go` — без `ServeTLS`, слушатель на петле;
  - `engine/agent_gateway.go` и `engine/agent_serve.go` — отдельный вход
    для потоков, приём потоков от жителя машины;
  - `internal/auth` — поток от шлюза не локальный;
  - `config.go` — умолчания адресов;
  - `-doctor` — проверка, что наружу ничего не слушает.
- **Житель машины** (репозиторий `sema-agent`):
  - `internal/gate` — режим «локальный шлюз»;
  - корень и выпуск сертификата;
  - запись имени (`/etc/hosts` или свой резолвер);
  - переход на VPS;
  - экран состояния у часов (`internal/desk`).
- **Развёртывание:**
  - `docker run` и compose без публикации 8765 и 8443;
  - nginx на VPS — HSTS, порт 80;
  - `auth.rp_id` и `auth.origin` — домен.
- **Связанные изменения:**
  - `agent-gateway` — живой запуск;
  - `login-phrase` — переезд ключей;
  - `perf-pass` 7.4 (переадресация `http` на `https`) теряет смысл:
    `http` в сети не будет;
  - `open-source` — «только через шлюз» становится одним из способов
    установки.
