## Why

Публикуемая версия Сёмы должна проходить проверки и собираться из основной ветки GitHub. Установка на сервере должна уметь забрать готовую проверенную сборку.

## What Changes

- Проверки pull request и основной ветки включают сборку, vet, Go-тесты, браузерные сценарии и поиск секретов.
- Успешный запуск основной ветки публикует пакеты GitHub Releases для Linux amd64 и arm64.
- Подписанный сигнал извещает Сёму о готовом выпуске. Служба обновления на хосте проверяет источник и контрольную сумму, запускает новую сборку и возвращает прежнюю при сбое.
- В настройках виден адрес webhook и доступен переключатель немедленной проверки. Расписание раз в 15 минут служит резервом.

## Capabilities

### New Capabilities

- `github-release-update` — выпуск сборок и обновление установки Docker.

## Impact

Публичный репозиторий, GitHub Actions, обработчик сигнала о выпуске и скрипт обновления Docker на хосте.
