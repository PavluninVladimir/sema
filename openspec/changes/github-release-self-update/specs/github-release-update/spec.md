## Purpose

Публикация проверенных пакетов Сёмы на GitHub и обновление серверной установки Docker.

## ADDED Requirements

### Requirement: Выпуск основной ветки

GitHub SHALL собирать пакеты основной ветки после успешных проверок. Версия MUST идентифицировать коммит. Настроенный получатель SHALL получать подписанное извещение о выпуске.

#### Scenario: Проверка не прошла

- **WHEN** одна из обязательных проверок завершилась ошибкой
- **THEN** новый выпуск не публикуется

### Requirement: Обновление Docker

Установка SHALL получать пакет только из выбранного репозитория и проверять его контрольную сумму. При неудачном запуске SHALL восстанавливаться прежний контейнер.

#### Scenario: Новая сборка не отвечает

- **WHEN** новая версия не проходит проверку здоровья
- **THEN** восстанавливается рабочая версия с теми же данными

### Requirement: Немедленная проверка обновления

Владелец SHALL видеть URL и состояние webhook GitHub в настройках обновлений Сёмы и иметь возможность включить или выключить немедленный запуск. В выдаче MUST отсутствовать ключ подписи. После проверки подписи, репозитория и времени запроса Сёма SHALL сигнализировать процессу обновления на хосте о готовом выпуске. Резервная проверка SHALL выполняться раз в 15 минут на рабочей установке.

#### Scenario: Получен подписанный сигнал

- **WHEN** настроенный GitHub Actions отправляет подписанный сигнал и немедленная проверка включена
- **THEN** процесс обновления проверяет выпуск сразу, через обычную проверку источника и контрольной суммы

#### Scenario: Немедленная проверка отключена

- **WHEN** владелец выключает немедленную проверку
- **THEN** подписанное извещение сохраняется, а проверка пакета выполняется по расписанию
