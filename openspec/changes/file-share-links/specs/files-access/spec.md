## ADDED Requirements

### Requirement: Файл по подписанной ссылке

Кроме выдачи вошедшему, сервер SHALL отдавать файл по действующей
подписанной ссылке без входа; путь ссылки SHALL быть в списке открытых
путей сервера и в списке путей шлюза.

#### Scenario: Открыли с телефона без входа

- **WHEN** ссылку открывают с телефона, где нет сессии Сёмы
- **THEN** файл открывается, а остальные адреса Сёмы по-прежнему требуют входа
