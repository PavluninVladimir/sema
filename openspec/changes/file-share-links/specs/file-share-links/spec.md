## Purpose

Подписанная ссылка на один файл Сёмы: её открывает тот, кому её дали, без
входа в Сёму, на срок и с отзывом, — чтобы скриншот бага открывался из
задачи Planner, а секретное наружу не уходило.

## ADDED Requirements

### Requirement: Ссылка на один файл

Сёма SHALL выдавать на файл ссылку на публичном адресе: подпись от ключа
из хранилища секретов, срок (по умолчанию из настройки), запись о выдаче
(кто выдал, откуда, когда). Подделанная, просроченная или отозванная ссылка
SHALL отвечать «нет такого» без подробностей. Каждое открытие SHALL
писаться в журнал ссылки.

#### Scenario: Скриншот бага

- **WHEN** Сёма выдаёт ссылку на скриншот #546 для задачи Planner
- **THEN** ссылка открывает картинку без входа в Сёму до конца срока

#### Scenario: Отзыв

- **WHEN** человек нажимает «Отозвать» у ссылки
- **THEN** ссылка больше не открывает файл

### Requirement: Что ссылкой не уходит

Файл класса «секретное» и файл из ящика, закрытого для облачной модели,
SHALL NOT получать ссылку ни от модели, ни от человека. «Чувствительный»
файл SHALL получать ссылку только по действию человека, а не модели. Класс
SHALL проверяться и при каждом открытии: файл, ставший секретным после
выдачи, по ссылке SHALL NOT отдаваться.

#### Scenario: Паспорт

- **WHEN** модель просит ссылку на скан паспорта
- **THEN** ссылка не выдаётся, модель получает причину отказа

### Requirement: Отдача по ссылке безопасна

По ссылке картинки (png, jpeg, webp, gif) SHALL отдаваться для показа на
месте, всё остальное — на скачивание; SVG и HTML — всегда на скачивание.
Ответ SHALL нести `nosniff`, песочницу CSP и не ставить cookie.

#### Scenario: SVG по ссылке

- **WHEN** по ссылке открывают SVG
- **THEN** он скачивается, а не исполняется в адресе Сёмы

### Requirement: Выдача из чата и из строки файла

Модель и модуль с правом на файлы SHALL мочь выдать ссылку инструментом и
получить адрес и срок; выдача из чата SHALL оставлять карточку с
«Отозвать». Строка файла на «Файлах» SHALL показывать действующие ссылки
(срок, открытий) с «Скопировать ссылку» и «Отозвать ссылки» и давать
человеку «Выдать ссылку».

#### Scenario: Картинка в заметку задачи

- **WHEN** модель заводит в Planner баг со скриншотом из Telegram
- **THEN** она выдаёт ссылку на файл и ставит её в заметку задачи, а в
  чате остаётся карточка ссылки с «Отозвать»
