## Why

3 октября 2026 владелец попросил Сёму завести в Planner баг со
скриншотом из Telegram («photo-…jpg», файл #546). Сёма завёл задачу, но
картинку приложить не смог — вписал в заметку только имя файла.
- У Planner в MCP нет загрузки файлов, а публичного API загрузки
  мы не нашли.
- Файлы Сёмы отдаёт только сам сервер и только вошедшему
  (`GET /api/files/<id>` под `protect`).

С 3 октября у Сёмы есть публичный адрес: шлюз `sema.example.org`
работает. Значит, Сёма может дать **ссылку на один файл**, которую
откроет тот, кому её дали, — без входа в Сёму, на ограниченный срок и
только для файлов, которые можно показывать.

## What Changes

- **Ссылка на файл** — `https://<публичный адрес>/share/<подпись>`:
  - один файл, срок (по умолчанию 30 дней, настройка);
  - отзыв в любой момент;
  - журнал открытий.
  - Подпись — HMAC от номера файла и срока на ключе из хранилища
    секретов. Подделать или продлить её нельзя.
- **Что делиться не может**: файлы класса «секретное» и файлы из
  закрытых ящиков — никогда. «Чувствительное» — только после вопроса
  человеку.
- **Ссылки из чата**: Сёма может выдать ссылку сам, когда кладёт файл во
  внешнюю систему (задачу Planner, письмо). Это видно карточкой
  «выдана ссылка на #546 до …» с кнопкой «Отозвать».
- **Экран файла**: «Ссылки» — кто выдал, срок, открытий, «Отозвать».
- **Шлюз** пропускает путь `/share/` (`semaPaths` у жителя машины) — та
  же правка шлюза в том же заходе, что и новая ручка Сёмы.

## Capabilities

### New Capabilities
- `file-share-links`: подписанная ссылка на один файл — срок, отзыв,
  журнал, запрет по классу, выдача из чата.

### Modified Capabilities
- `files-access`: кроме выдачи вошедшему, файл отдаётся по действующей
  подписанной ссылке.

## Impact

- API: открытая ручка `/share/<подпись>`. Список открытых путей —
  `openPath`, его держит `TestOpenPathsAreListed`.
- Хранилище: таблица `file_shares`; ключ подписи — в хранилище
  секретов.
- Движок: выдача ссылки (`ShareFile`), проверка класса, инструмент для
  модели и модулей.
- Экран файла; карточка в чате.
- Шлюз (`semaagent/internal/gate/filter.go`): путь `/share/`, пределы
  частоты на нём.
- Зависит от того, что шлюз работает (`agent-gateway`). Без публичного
  адреса ссылка работает только в своей сети.
