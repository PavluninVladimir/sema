## Context

Зачем — см. proposal.md.

- Файлы — сущность ядра:
  - `GET /api/files/<id>` под `protect` отдаёт байты с `attachment`,
    `nosniff` и `CSP sandbox` (аудит 7 сентября);
  - класс файла хранится (`content_class`) и пересчитывается, когда
    появился текст.
- Открытые пути — один список `openPath` (`TestOpenPathsAreListed`).
  Шлюз пускает только известные пути (`semaPaths`): новая открытая
  ручка — правка шлюза в том же заходе.
- Planner: в MCP нет загрузки файлов. Ссылка в заметке задачи —
  единственный способ показать картинку.

## Goals / Non-Goals

**Goals:** скриншот бага открывается из задачи Planner по ссылке; ни
секретное, ни файл из закрытого ящика ссылкой не уходят.

**Non-Goals:** публичная галерея, папки по ссылке, загрузка файлов
снаружи.

## Decisions

1. **Подпись, а не случайный номер в базе.** `/share/<id>.<срок>.<hmac>`,
   HMAC-SHA256 на ключе `share:key` из хранилища секретов. Проверка без
   похода в базу, а отзыв — строкой в `file_shares` (её проверяем после
   подписи). Смена ключа гасит все ссылки разом — это аварийный рубильник
   «Отозвать все».
2. **Класс решает**: «секретное» и файлы закрытых ящиков — отказ при
   выдаче, а также при открытии (класс мог подняться после выдачи).
   «Чувствительное» — по вопросу человеку, как согласие по отправителю.
3. **Отдача** — те же заголовки, что у `/api/files`: `attachment` для
   всего, кроме картинок; картинки — `inline`, чтобы Planner и
   браузер показали их; `nosniff`; `CSP sandbox`; без cookie.
4. **Выдача моделью**: инструмент `sema.files.share(id, {days})` по праву
   `files`, а в чате — блок, который Сёма исполняет и показывает
   карточкой с «Отозвать». Срок по умолчанию — `share.days` (30) в
   реестре.
5. **Шлюз**: путь `/share/` в `semaPaths`, предел частоты — как у входа.
   Перебор подписей отсекается и подписью, и пределом.

## Risks / Trade-offs

- [Ссылку переслали дальше] → срок, отзыв, журнал открытий; отказ для
  секретного и закрытых ящиков.
- [Класс поднялся после выдачи] → проверка класса при каждом открытии.
- [Картинка `inline` исполнит что-то] → только растровые типы `inline`
  (png, jpeg, webp, gif), SVG — всегда `attachment`.

## Migration Plan

1. Ключ подписи и `file_shares`; ручка `/share/` и `openPath`.
2. Шлюз: путь `/share/`.
3. Экран файла: «Ссылки».
4. Инструмент и блок в чате.
5. На живом: баг в Planner со скриншотом #546 по ссылке открывается
   с телефона без входа; отзыв — 404.
