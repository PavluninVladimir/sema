## Context

Зачем — см. proposal.md.

- Публикация:
  - `toolTGPost` — каналы с правом «Писать», картинка, превью ссылки
    (`waitPreview`), предел `tg.posts_per_day`;
  - `toolMAXPost` — картинка фотографией (опкод 80), предел
    `max.posts_per_day`.
- Архив Telegram (`tg_messages`) кладёт своё сообщение, отправленное
  по соединению слушателя, сам (эхо не приходит); номер есть.
- Правка текста в Telegram — `editText` (`tg/live.go`) по `Peer` и
  номеру. Для поста с картинкой правится подпись (`messages.editMessage`
  с тем же `media`).

## Goals / Non-Goals

**Goals:** «исправь последний пост» в чате доводит до правки с кнопкой;
журнал показывает, что и когда правилось.

**Non-Goals:** правка чужих постов в канале (только выпущенных Сёмой или
владельцем через Сёму); замена картинки (только текст и подпись).

## Decisions

1. **Журнал постов** — таблица `channel_posts`: мессенджер, канал, номер,
   текст, картинка (номер файла), кто просил (чат, модуль), когда, правки
   («было» → «стало», когда, кто). Публикация пишет строку, правка —
   дописывает.
2. **Инструменты** — `sema.telegram.edit` и `sema.max.edit`, право то же,
   что у публикации. Номер необязателен: без него — последний пост Сёмы в
   канале из журнала.
3. **Кнопка по умолчанию**: из чата правка — карточка «было → стало»
   (как предложение скилла) с «Править» и «Отмена». Из модуля — по
   праву, без кнопки: модуль выдан человеком с этим правом.
4. **MAX** — разведка опкода правки сообщения. Нет его — инструмент
   отвечает «правка в MAX недоступна» и предлагает пару «удалить и
   выпустить заново» той же карточкой.

## Risks / Trade-offs

- [Правка видна подписчикам] → кнопка по умолчанию, журнал правок.
- [Пост с картинкой правится иначе] → тест на посте с картинкой и с
  превью; при `MESSAGE_NOT_MODIFIED` — «текст не изменился», а не ошибка.

## Migration Plan

1. Журнал постов и возврат номера.
2. `sema.telegram.edit` с карточкой.
3. Разведка и `sema.max.edit`.
4. На живом: правка поста «Погода» в обоих каналах.
