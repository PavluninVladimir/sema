## MODIFIED Requirements

### Requirement: Интерфейс не залипает

Клиент SHALL оставаться отзывчивым во время долгих операций и SHALL NOT
терять место в списке при обновлении экрана. Переключение разделов SHALL
показывать выбранный раздел сразу, не дожидаясь ответа сервера. Ответ
Сёмы SHALL появляться по мере написания, а изменение на сервере SHALL
становиться видно на открытом экране без действия человека.

#### Scenario: Длинный список писем

- **WHEN** в разборе тысячи писем
- **THEN** список подгружается частями по запросу, а окно не подвисает

#### Scenario: Ответ по мере написания

- **WHEN** Сёма пишет ответ в открытом чате
- **THEN** текст появляется по мере написания, а не по таймеру раз в несколько секунд

#### Scenario: Чужое изменение

- **WHEN** задача по расписанию положила сообщение в открытый чат
- **THEN** сообщение появляется на экране без нажатия
