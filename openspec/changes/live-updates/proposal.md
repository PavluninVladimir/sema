## Why

Веб-клиент узнаёт об изменениях опросом: экран с полем ввода дёргает `/ui`
каждые четыре секунды, остальные экраны не обновляются вовсе, пока человек
не нажмёт. Ответ Сёмы в чате приходит рывками по четыре секунды, новое
уведомление на другом экране не видно, а на телефоне опрос жжёт батарею и
трафик впустую — девяносто девять запросов из ста возвращают то же самое.
PWA на телефоне — основной способ пользоваться Сёмой с сентября 2026, и
для него это заметно каждый день.

## What Changes

- Постоянное соединение по WebSocket между веб-клиентом и Сёмой:
  сервер сообщает, **какой экран изменился**, клиент перезапрашивает его
  той же дорогой `/ui`. По проводу не ходит ни разметка, ни данные —
  только сигналы.
- В движке появляется одно место, откуда идут сигналы «экран устарел»:
  переписка, ответ модели по мере написания, уведомления, письма, задачи.
- Опрос остаётся запасным путём и делается редким, пока провод живой;
  провод оборвался — клиент возвращается к прежнему опросу сам. Частоты —
  настройки, не константы.
- На телефоне соединение переживает уход в фон: при возвращении
  переподключается и перечитывает экран один раз.
- Меню (счётчики уведомлений, точка «Здоровья») обновляется по сигналу,
  а не при следующем переходе.

## Capabilities

### New Capabilities
- `live-updates`: живое обновление экрана по сигналу с сервера, с опросом
  как запасным путём; права, происхождение и пределы соединения.

### Modified Capabilities
- `dynamic-ui`: требование «Интерфейс не залипает» дополняется — ответ Сёмы
  появляется по мере написания, а не по таймеру, и экран обновляется
  после чужого изменения без действия человека.

## Impact

- `server/internal/engine` — узел сигналов и вызовы из мест, где меняется
  то, что показывают экраны.
- `server/internal/api` — ручка `/api/ws` под тем же `protect`, проверка
  источника соединения.
- `server/internal/web/static/app.js`, `markup.go` — подписка, переподключение,
  переход между проводом и опросом.
- Зависимость `github.com/coder/websocket` уже есть в `go.mod` (клиент Max);
  новых не появляется, cgo не нужен.
- `Sema.app` не меняется: его опрос с ETag остаётся как есть, ручка
  спроектирована так, чтобы он мог подписаться позже.
