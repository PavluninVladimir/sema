# Словарь Сёмы

Два языка и граница между ними: **код и архитектура — по-английски,
интерфейс и комментарии — по-русски**. Человек читает экран на родном
языке, разработка называет узлы общепринятыми словами.

Правило простое: имя в коде берётся из левой колонки, слово на экране — из
средней. Новый термин заводится здесь, а не в голове.

Здесь — **узлы**: что такое шлюз, чем он отличается от агента. Слова, из
которых складываются имена полей и тестов (`итог`, `срок`, `проверка` — у
каждого по два-три разных смысла), — в `NAMES.md` рядом. Как узлы связаны
между собой — в `ARCHITECTURE.md`.

## Узлы

| В коде и архитектуре | На экране | Что это |
|---|---|---|
| `Sema Agent` | «агент», «житель машины» | программа на машине пользователя (macOS или Linux): понимание кода, дверь в память для агентов разработки, значок у часов |
| `Sema Gateway` | «шлюз» | программа на внешнем сервере: принимает браузеры из интернета и передаёт их домой |
| `Sema Tunnel` | «связь со шлюзом» | защищённое соединение между Сёмой и шлюзом; соединение открывает Сёма |
| `Control Channel` | «управляющий канал» | тонкий провод JSON-RPC: запросы, ответы, пинги |
| `Data Stream` | «поток» | отдельное соединение под один запрос браузера; в управляющий канал потоки не пускают |
| `Public Endpoint` | «внешний адрес» | адрес, куда звонит Сёма; один на всё, чтобы на роутере открывалась одна строка |
| `Edge` | «край» | кто стоит лицом к интернету и держит публичный сертификат; обычно это nginx перед шлюзом, а не сам шлюз |

## Правила и политики

| В коде | На экране | Что это |
|---|---|---|
| `Request Filter` | «отбор запросов» | на шлюзе: известные пути пропускаются, незнакомые нет, плюс пределы частоты |
| `Access Policy` | «Разрешить / Спросить / Запретить» | ответ правила на команду или вызов: `Allow` — выполняется сразу, `Ask` — ждёт человека (у самостоятельного сервера — суда), `Deny` — не выполняется. **Не подошло ни одно правило — `Deny`**: так же у нового сервера, новой команды и нового инструмента |
| `Access Rule` | «правило» | образец и ответ у одного сервера (`host_rules`) либо инструмент и ответ у сервера MCP (`mcp_servers.rules`). Правила у каждого сервера свои |
| `Rule Set` | «набор „Linux“ / „RouterOS“» | готовое заполнение для сервера без правил. Копируется, а не привязывается: дальше правила сервера живут своей жизнью |
| `Rule Request` | «нет правила» | команда, которой не подошло ни одно правило: запрещена по умолчанию, человек решает кнопками «Спрашивать для неё» / «Разрешить её» (`ssh_norule`). Запрет по правилу «Запретить» запросом не бывает — кнопок у него нет |
| `New Tool` | «новый» | инструмент сервера MCP, про который человек ещё не решал: в правилах его нет, действует «ответ для нового» (по умолчанию `Deny`), модель его не видит |
| `Retention Policy` | «что можно хранить» | можно ли положить экран на устройство. **Нет ответа — значит нельзя** |
| `Capability` | «способность» | что человек разрешил агенту поимённо |
| `Role` | «роль» | роль экземпляра агента: `agent` (житель машины) или `gateway` (шлюз); в одном экземпляре не совмещаются |

## Данные и состояния

| В коде | На экране | Что это |
|---|---|---|
| `Cached Screen` | «снимок экрана» | сохранённый **документ** экрана для чтения без связи. **Не картинка** — разметка, которую клиент рисует заново |
| `Snapshot Build` | «снимочная сборка» | та же сборка экрана, но с вырезанным закрытым и секретным |
| `Exclusion` | «отсев» | что не попадает в снимок: закрытые ящики, класс «секретное» |
| `Outbox` | «исходящие» | написанное без связи, ждущее отправки |
| `Inventory` | «опись» | перечень того, чем Сёма располагает; уходит в промпт модели |
| `Session Summary` | «итог сессии» | сжатый итог работы, который ложится в память |
| `Cooldown` | «передышка» | пауза у роли, чья модель перестала отвечать |
| `Fallback Tier` | «ступень», «ярус» | чем добыт ответ о коде: языковой сервер, справочник символов, поиск по тексту |

## Проверки

| В коде | На экране | Что это |
|---|---|---|
| `Marker` | — | редкое слово в тестовых данных: видно его там, где не должно, — утечка |
| `Regression Guard` | — | тест, который держит закрытой уже найденную дыру |

## Чего не берём, и почему

- **`Screenshot`** — у нас не картинка, а документ экрана. Слово увело бы
  человека искать изображение.
- **`Tunnel` в одиночку** — у связки две разные части, управляющий канал и
  потоки, и весь смысл в том, что они разведены. Одно слово это прячет.
- **`Token` для `Marker`** — токен в проекте уже занят: это ключ доступа.
